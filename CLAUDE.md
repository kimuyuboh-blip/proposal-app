# CLAUDE.md - Learning Project Guidelines

## My Tech Stack
- **Frontend:** React (Vite), JavaScript, HTML5, CSS3
- **Styling:** Standard CSS (clean modules) or Tailwind CSS

## Developer Commands
- **Start the app server:** `npm run dev`
- **Build application:** `npm run build`

## Teaching Rules for Claude
- **Educational Explanations:** Explain how React components manage changing views (like clicking "Yes").
- **Fun Animations:** Help me add smooth transitions, floating hearts, or moving button components.
- **Interactive Logic:** Guide me on how to make the "No" button move away or shrink dynamically.
